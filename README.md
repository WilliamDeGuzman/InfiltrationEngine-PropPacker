# InfiltrationEngine-PropPacker
Utility for using multiple prop packs at once, handling props with the same name and nested folders. Removes custom props that aren't needed.

For most users, all you need to do is to add a folder to your DebugMission named "CustomPropPacks" then drag and drop your prop packs there.

For makers of prop packs, it is preferred to add these attributes to your rbxm folder:

| Attribute           | Type    | Example         |
| ------------------- | ------- | --------------- |
| Author              | String  | mrwd            |
| License             | String  | CC BY-NC-SA 4.0 |
| RequiresAttribution | Boolean | true            |
